# SolarFlow - Home Assistant Addons

MQTT Topic Transformer für Zendure SolarFlow über lokales MQTT.
Kein DTU, keine Cloud, kein Token nötig.

| Addon | Geräte |
|-------|--------|
| `solarflow-hyper` | Hyper 2000 |
| `solarflow-hub` | Hub 2000 + ACE 1500 |

## Installation

1. Repository in HA hinzufügen: `https://github.com/dhaucke/addon-solarflow-hyper`
2. Passendes Addon installieren und konfigurieren
3. Starten

Beide Addons nutzen dasselbe Skript (`test_solarflow.py` prüft, dass die Kopien gleich sind).
